# Simplified Chinese translation style notes

This document records translation choices for Simplified Chinese RouteVN pages.

Use this for website copy, SEO text, landing pages, product pages, and future Simplified Chinese documentation.

## Goal

Simplified Chinese copy should sound like a Chinese product page for a visual novel and Galgame creation tool.

Do not translate English literally. Rewrite copy so it is clear, natural, and useful for Chinese-speaking visual novel creators.

Use Simplified Chinese for `zh-hans` pages. Use Mainland-style punctuation and wording unless a page is explicitly targeting another Chinese-speaking region.

## Core terminology

Use these terms consistently:

- `视觉小说`: Use this as the main genre term.
- `视觉小说制作`: Use for creating visual novels.
- `视觉小说制作工具`: Use for RouteVN Creator in broad product copy.
- `视觉小说引擎`: Use when talking about engine-level capabilities, technical architecture, or comparison with Ren'Py, 吉里吉里, or other engines.
- `Galgame`: Use only as a secondary community or SEO term. It is familiar in Chinese VN communities, but narrower than `视觉小说`.
- `游戏制作`: Use when talking about making games broadly.
- `项目`: Use for project.
- `剧本`: Use for story script or scenario writing.
- `脚本`: Use for technical scripts, code-like files, or engine scripting.
- `角色`: Use for character.
- `立绘`: Use for character sprites in visual novel context.
- `背景图`: Use for background images.
- `CG`: Use for special event illustrations when the context is visual novel art.
- `素材`: Use for assets in beginner-facing copy.
- `素材管理`: Use instead of `资产管理器` when possible.
- `场景`: Use for scenes.
- `场景图`: Use for scene map only if the app UI uses this concept; otherwise explain as `场景流程`.
- `对话`: Use for dialogue.
- `旁白`: Use for narration.
- `台词`: Use for spoken lines when referring to content written for characters.
- `选项`: Use for choices.
- `分支`: Use for branching.
- `分支选项`: Use when describing choices that lead to branches.
- `剧情分支`: Use when emphasizing the story structure.
- `转场`: Use for transitions.
- `实时预览`: Use for live preview.
- `布局编辑`: Use for layout editing.
- `画面布局`: Use for screen layout.
- `导出`: Use for export output when talking about generated files.
- `发布`: Use for publishing or making a game available to players.
- `Web 版`: Use for the web build or web version.
- `存档`, `读档`, `回滚`: Use for save, load, and rollback when talking about player-facing VN features.

Avoid these as primary terms:

- `可视小说`: Incorrect or unnatural. Use `视觉小说`.
- `图像小说`: Means graphic novel in many contexts. Use `视觉小说`.
- `视觉文学`: Too literary and not the usual product category. Use `视觉小说`.
- `美少女游戏`: Too narrow unless the page is specifically about that subgenre.
- `文字冒险`: Useful as a related genre term, but do not use it as the primary RouteVN category.
- `AVG`: Familiar to some users, but too ambiguous for broad product copy.
- `资产`: Too literal for asset. Prefer `素材`.
- `资产管理器`: Too technical for broad product copy. Prefer `素材管理`.
- `实时编辑器`: Avoid unless naming an exact UI concept. Prefer `实时预览`.
- `强大`: Usually sounds like generic marketing. Prefer a concrete benefit.
- `无编码`: Awkward. Prefer `无需编程` or `不用写代码`.

## Tone

Use clear, direct Simplified Chinese.

- Prefer short sentences.
- Use natural product copy, not machine-translated English.
- Write for creators, writers, artists, hobbyists, and small teams.
- Prefer concrete benefits over abstract adjectives.
- Keep the tone practical and friendly.
- Avoid stiff corporate phrasing.
- Avoid slang-heavy copy, memes, and fandom in-jokes on general product pages.

## Product positioning

RouteVN Creator should be described as:

- A tool for `视觉小说制作`.
- Usable without programming.
- Relevant to creators who know `视觉小说`, `Galgame`, or `VN` communities.
- Useful for writing, character art, scene layout, branching, preview, asset organization, export, and publishing.
- Beginner-friendly, but not toy-like.

Good phrasing:

- `无需编程，也可以制作视觉小说。`
- `修改剧本或演出后，可以在预览画面中立即查看效果。`
- `立绘、背景图、音频等素材可以集中管理。`
- `通过选项和剧情分支组织不同路线。`
- `完成后可以导出 Web 版并发布到网上。`

Avoid:

- `没有编码即可创建可视小说。`
- `强大的实时编辑器。`
- `资产管理器可以管理所有资产。`
- `把你的故事变成视觉新颖。`

## Page headings

Headings should describe the benefit plainly.

Preferred examples:

- `把你的故事做成视觉小说`
- `实时预览`
- `视觉小说制作需要的功能，集中在一个工具里`
- `立绘、背景图和音频素材管理`
- `选项与剧情分支`
- `FAQ`

Avoid headings that feel translated from English:

- `让你的视觉小说活起来`
- `强大的实时编辑器`
- `所有视觉小说功能`
- `无编码视觉小说创造者`

## Feature names

Use Chinese labels when they are clearer:

- `画面布局编辑`, not `布局编辑器`, for marketing/card headings.
- `素材管理`, not `资产管理器`.
- `选项与剧情分支`, not `Choices and Branching`.
- `发布`, not `Publishing`.
- `实时预览`, not `Live Editor`.

Keep established UI/tool terms if the app itself uses them in English, but explain them in Chinese if needed.

Distinguish between product marketing copy and in-app feature names:

- Use natural Chinese benefit labels in page headings and cards.
- Use exact in-app names only when the page is teaching where to click or what the user sees in the UI.
- If an English source label is a feature name, do not automatically transliterate it. First ask whether a Chinese creator would understand the benefit from the label alone.

Examples:

- Marketing/card heading: `画面布局编辑`.
- In-app feature reference: `Layout Editor` or the localized UI label if the app has one.
- Marketing/card heading: `素材管理`.
- In-app feature reference: `Asset Manager` or the app's exact UI label, if the UI is not localized.

## Visual novel and Galgame wording

Use `视觉小说` as the default genre term on product pages.

Use `Galgame` only when it helps users find the page or when the copy is clearly speaking to that community. `Galgame` often implies romance, anime-style, or Japanese-style VN culture. RouteVN should not sound limited to that subgenre unless the page intentionally targets it.

Use `视觉小说引擎` for technical pages and SEO where users are likely comparing tools like Ren'Py, 吉里吉里, NVL Maker, BKEngine, TyranoBuilder, or Visual Novel Maker.

Use `文字冒险` only as a related genre or comparison term. It can describe ADV-style games, but it should not replace `视觉小说` for RouteVN's main positioning.

## Export and publishing wording

Use `导出` when referring to generated files.

Use `发布` when referring to making the game available to players.

Example:

`目前可以导出 Web 版。导出后会生成 HTML 和 JavaScript 文件，你可以把它发布到网站上。`

## Links on Simplified Chinese pages

Until Simplified Chinese docs exist, Simplified Chinese landing pages may link to existing English pages.

When doing this:

- Keep the visible label Chinese, such as `文档`.
- Point the link to the existing `/en/...` page.
- Do not create `/zh-hans/...` links unless that page exists.

## SEO notes

Simplified Chinese SEO text should include natural Chinese search terms:

- `视觉小说制作`
- `视觉小说制作工具`
- `视觉小说引擎`
- `Galgame 引擎`
- `Galgame 制作`
- `无需编程`
- `不用写代码`
- `游戏制作`
- `立绘`
- `剧情分支`

Use `VN` as a secondary keyword if useful. Do not make it the main term.

## Review checklist

Before finishing any Simplified Chinese translation, review the page line by line.

Check every heading, card title, CTA, FAQ label, SEO field, and alt text for these issues:

- Literal English structure.
- Unnatural transliteration.
- English feature names used where Chinese benefit wording would be clearer.
- Avoided terms from this document.
- Mixed terminology for the same concept.
- Traditional Chinese terms or characters on `zh-hans` pages.
- Links that point to `/zh-hans/...` before the Simplified Chinese target page exists.
- SEO terms that do not match likely Chinese search language.

For every feature/card title, ask:

- Is this a public marketing label or an exact in-app UI reference?
- Would a Chinese visual novel creator understand what this does without reading the English source?
- Can this be phrased as a natural benefit rather than a translated noun phrase?

Do not mark a Simplified Chinese page ready until this checklist has been applied.
