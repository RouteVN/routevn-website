These are the keyboard shortcuts available in RouteVN Creator.

## Introduction

RouteVN Creator is designed so that:

- All operations can be done via mouse.
- All operations can be done via keyboard only.

For users who spend a lot of time in this application, we recommend investing at least some time to learn and use the most commonly used keyboard shortcuts. It is a more efficient way of working and feels better.

The keyboard shortcuts were heavily inspired by Vim/Neovim.

There are a few types of shortcuts:

- [Global navigation](#global-navigation)
- [Page-specific shortcuts](#page-specific-shortcuts)
- [Scene editor shortcuts](#scene-editor-shortcuts)
- [Layout editor shortcuts](#layout-editor-shortcuts)
