title: Toggle Auto Mode
sidebarId: toggle-auto-mode
---

Use this command to toggle automatic line progression for the selected context.

- It enables or disables auto playback-like flow.
- Useful when replaying long narrative sequences.
- Use with caution in scenes that require precise player input.
- Keep auto mode changes visible in your scene map review.
- This command is part of system actions.
