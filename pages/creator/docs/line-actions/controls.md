Use this action to adjust scene-level interaction behavior.

- `disableUserClick` controls whether click progression is blocked.
- `autoPlay` controls automatic playback of lines.
- `autoPlayDelay` sets delay time for autoplay.
- Good for test scenes where player input should be temporarily disabled.
- Pair with toggle commands for more explicit flow control.
