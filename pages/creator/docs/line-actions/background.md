Use this action to set the scene background for the current frame.

- `background.resourceId` points to the background asset.
- `background.resourceType` supports image, layout, or video backgrounds.
- `background.animations.in` defines the entry animation.
- `background.loop` controls whether the background repeats when possible.
- You can create mood changes without changing the whole scene.
