Background sets the main visual backdrop for the current line.

## Background sources

Background can use 3 resource types:

- [Images](/creator/docs/images/)
- [Videos](/creator/docs/videos/)
- [Layouts](/creator/docs/layouts/)

When selecting a layout as a background, only layouts with the `General` type are shown.

## Selecting a background

To select a background:

1. Click the background preview area.
2. Choose the `Images`, `Layouts`, or `Videos` tab.
3. Select the resource you want to use.
4. Click `Select`.

Use the search field when the resource list is large.

## Transform

Use Transform to apply a reusable [transform](/creator/docs/transforms/) to the background.

Transforms can change the background position, scale, and anchor.

## Animations

Animation controls whether the background uses an [animation](/creator/docs/animations/).

The available animation modes are:

- `None`: no animation
- `Update`: animate the current background
- `Transition`: animate the change from one background to another

### Playback Continuity

Playback Continuity appears when Animation is set to `Update` or `Transition`.

Use `Current Line` for normal animation playback. Use `Persistent` when the animation should keep persistent playback state.

## Loop Video

Loop Video appears when the selected background is a video.

Use `Loop` when the video should repeat. Use `Don't Loop` when the video should play once.

## Removing a background

To remove the selected background:

1. Right click the background preview.
2. Select `Remove`.
3. Click `Submit`.
