Use this action to change variable values during line execution.

- `updateVariable.id` is the variable being updated.
- `updateVariable.operations` contains the operation list.
- This is useful for flags, counters, and branching state.
- Keep variable names stable across scenes and scripts.
- Track updates with your branching flow review.
