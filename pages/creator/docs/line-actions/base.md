Use this action to set the base layout for presentation content.

- `base.resourceId` is the selected base layout asset.
- `layouts` provides available templates for the editor.
- Base layout helps standardize position and structure for scene lines.
- Use this before adding content-specific commands on the same line.
- Update the base when the visual hierarchy changes.
