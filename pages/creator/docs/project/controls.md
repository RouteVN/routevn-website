Controls connect user events such as mouse clicks and keyboard presses into actions

## Mouse events

- It uses layout editor where you can add an area for click events

Common events are left mouse click to go to next line, and right mouse click to hide the dialogue.

With the layout editor, it is possible to control the area of the mouse click that is affected.

## Keyboard events

- Specify keyboard key and trigger actions
