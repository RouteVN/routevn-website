Use transforms to set position, scale, rotation, and opacity for scene elements.
Commonly used for position of characters,  background, or other visual assets.
Defining transforms ensures consistency.

## Supported properties

- Position X and Y
- Scale X and Y dimensions
- Rotation
- Opacity

## Creating a transform

- A transform requires at least 1 properly
- The preview will appear right side of the editor
