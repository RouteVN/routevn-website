Use transforms to position, resize, rotate, and fade elements in scenes and UI.

Use transforms to control the transform layer for scene and UI assets.

- Adjust scale, position, and rotation from a reusable transform preset.
- Use transform entries when you need consistent character pose or prop placement.
- Keep these settings lightweight so scene previews remain snappy.
- Reuse presets across scenes to reduce drift during updates.

<img src="/public/creator/docs/reference/project-flow.webp" style="width: 100%; margin-bottom: 20px;" alt="Transform presets in resource workflow">

Prefer conservative values while prototyping, then standardize as your art style settles.
