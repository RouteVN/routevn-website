Use transforms to set position, scale, rotation, and opacity for scene elements.
Commonly used for characters, and visuals position. 

## Supported transform properties

| Action | Purpose | Typical use |
|---|---|---|
| Position | Move element location | Align character and object placement |
| Dimensions | Resize element | Keep proportions across scenes |
| Rotation | Tilt/angle adjustment | Fine pose and style tweaks |
| Opacity | Fade in/out | Scene transitions and visual polish |

## Creating a transform

- A transform requires at least 1 properly
- The preview will appear right side of the editor
- It is possible to change the preview image

## Usage

Transforms are used in:

- Scene editor for character, visuals placement
- UI layouts for consistent visual rhythm
