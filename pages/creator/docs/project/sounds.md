Use this page to configure audio in RouteVN Creator.

1. Import music and SFX files into the asset manager.
2. Preview playback in the editor.
3. Reuse tracks with loops where appropriate.
4. Keep volume and transitions consistent across scenes.

Name assets with a consistent pattern (for example `bgm_`, `sfx_`, `vo_`) to keep large projects organized.
