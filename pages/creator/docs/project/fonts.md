Pick and register fonts to keep typography readable and on-brand.

- Upload and register font files from the font resource page.
- Use one display font and one body font for consistent hierarchy.
- Keep fallback fonts configured to avoid missing-font regressions.
- Test line wrapping on small and large viewport sizes.

## Supported Font Formats

| Format | Note |
| --- | --- |
| `.ttf` | Preferred for broad compatibility |
| `.otf` | Works well for display and stylized typefaces |
| `.woff` | Common web-safe packaging format |
| `.woff2` | Compressed and optimized modern format |

Avoid changing families mid-project unless you also update style presets.
