## Supported font formats

- `ttf`
- `otf`
- `woff`
- `woff2`

## Upload fonts

You can upload single or multiple fonts for your project.

- Click the upload button, and select single or multiple font files
- Drag and drop font files directly into the folder

## Previewing a font

Double click font item to preview the font glyphs
