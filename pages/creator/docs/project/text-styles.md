Text styles is to manage the typography

Common text styles to create are:

- Character name
- Dialogue content
- Menu text

## Create a text style

- Name
- Description
- Font file
- Font size
- Font weight
- Line height
- Preview text: defaults to name
- Storke color
- Stroke width

## Usage

Text styles are used in:

- Layout editor
