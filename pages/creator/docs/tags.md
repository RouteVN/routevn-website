Tags are labels that help you organize resources and find related items quickly.

They add another way to organize items in addition to folders. Because one item can have multiple tags and one tag can be used by many items, tags are flexible.

Tags are available for all resources.

## Tag scopes

Tags are separate for each resource area. For example, image tags are separate from sound tags.

Character sprite tags are also separate for each character.

## Assigning tags

Tags can be assigned to resource items.

Folders cannot have tags.

To assign tags to an item:

1. Select an item to display the right detail panel.
2. Click the tags area or `Add tag`.
3. Select existing tags that you want to assign, or create a new tag.
4. Press submit.

Some notes:

- Tags cannot have the same name.
- You can change the name of tags.
- An item can have as many tags as you assign.

## Filtering by tags

Use the tag filter in the page header to show items with selected tags.

When you select multiple tags, RouteVN Creator shows items that match any selected tag.

## Character Sprite Tags

For character sprites, tags are also used to implement grouped sprites.
