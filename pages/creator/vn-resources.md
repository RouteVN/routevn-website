# Asset Platforms

## Itch.io

Itch.io may be primarly know for publishing actual finished games, but actually they have a section for assets and resources as well.

The following tags are useful:

https://itch.io/game-assets/free/genre-visual-novel/tag-backgrounds

There are both free and paid resources. Licenses vary per asset, make sure to check the license for each.

## Booth

Booth () is a platform for publishing all kinds of digital work including assets and resources

It is operated by Pixiv the popular illustartor website in Japan. The interface is in Japanese, but there is also interface in English. The content description itself is in Japanese. You are recommended to use a translator or something if you can't read Japanese.
