## Changes

- Major version update with a breaking change for projects created with `v0.17.0` and below
- Older projects need to be migrated manually; contact support if you need help upgrading them
- Improve overall polish, design consistency, and usability across the app
- Improve stability and fix bugs across common workflows
- Load images and videos on demand directly from disk, reducing RAM usage by around 50% when working with larger videos
- Layout Editor now ships with a fully functioning default UI, including Dialogue ADV, Dialogue NVL, title page, menu page, save/load pages, and options page
- Users can keep the default template, replace the UI assets, or customize layouts and events further without coding
- Stronger foundation for upcoming features such as spritesheets, particles, history log, keyboard shortcuts, variables, user input, rich text support, and richer dialogue controls
