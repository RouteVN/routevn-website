This version adds screen transition animation support and layout editor scroll events. It also fixes sound volume changes and improves animation previews.

## Changes

- Add screen transition animation support
- Add support for scroll up and down events in the layout editor
- Fix sound volume changes not working
- Simplify the character and background animation selector
- Improve animation list and animation editor page previews
- Change layout item ordering to match other design apps, so the top item appears in front
