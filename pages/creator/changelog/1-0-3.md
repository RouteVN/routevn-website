## Changes

- Version `1.0.3` includes a breaking change for projects created with `v0.17.0` and below. Older projects need to be migrated manually; contact support if you need help upgrading them
- Improve overall polish, design consistency, and usability across the app
- Redesign the Animation Editor page
- Improve stability and fix bugs across common workflows
- Improve performance when working with large images and videos
- Layout Editor now ships with a fully functioning default UI, including Dialogue ADV, Dialogue NVL, title page, menu page, save/load pages, and options page. Users can keep the default template, replace the UI assets, or customize layouts and events further without coding
