## Changes

- Add Appearance page for selecting the app theme
- Add Particles page for creating effects such as snow and rain
- Add Spritesheets page for spritesheet animations
- Add multipart character sprite group support for character expressions and layered sprites
- Add dialogue character conditions in Layout Editor
- Add release web server support for testing exported web builds locally
- Optimize export bundle packaging and runtime loading for smaller exported builds and faster startup
- Improve Layout Editor interaction performance
- Improve file explorer and preview keyboard navigation
- Change tag filters to match any selected tag
- Polish help links and character selection flows
- Fix scene editor preview, presentation state, dialogue command line, Linux canvas rendering, and VN preview sizing issues
