RouteVN Web Extractor is a browser extension that helps you read visual novels in other languages with a pop-up dictionary.

## Install the extension

1. Open [RouteVN Web Extractor in the Chrome Web Store](https://chromewebstore.google.com/detail/routevn-web-extractor/mmaeimemigaiffcbhaaplmgkoimijcik) in Chrome.
2. Select **Add to Chrome**.
3. Review the permissions and select **Add extension** to finish installing.

## What you can do

- Look up words in a pop-up dictionary.
- Browse the history of extracted dialogue and choices.
- Save words to Anki with AnkiConnect.

The [Using the Dictionary guide](/en/web-extractor/docs/using-the-dictionary/) is being written.
