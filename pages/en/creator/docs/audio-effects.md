Audio Effects define reusable changes to audio playback.

There are 2 types of audio effects:

- Update effects change the volume, pan, or playback rate of a sound that is already playing.
- Transition effects fade between the previous and next sounds.

## Create an audio effect

1. Open `Project > Audio Effects`.
2. Click `Add`.
3. Enter a name and choose `Update` or `Transition`.
4. Open the effect to edit it.

Use folders and tags to organize effects.

## Audio Effect Editor

Double-click an effect to open the Audio Effect Editor.

To edit an effect:

1. Use the `Timeline` tab to add properties and keyframes.
2. Set each keyframe's value, delay, duration, and easing.
3. For a transition effect, edit the separate timelines for the previous and next sounds.
4. Use the `Preview` tab to choose sounds and test the result.
5. Click `Back` to save the effect.
