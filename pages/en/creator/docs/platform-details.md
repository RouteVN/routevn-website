Platform Details stores the metadata used when exporting your project.

## Configure a platform

1. Open `Project > Releases > Platform Details`.
2. Click `Add Platform` and choose Web, Windows, or macOS.
3. Enter the application name and identifier.
4. Add an icon for Windows or macOS.
5. Save the details.

Configure the platform before creating an export from [Versions](/en/creator/docs/versions/).
