This page gives an overview of the main pages inside RouteVN Creator.
Use it as a quick index when you want to understand where a feature lives before going into the detailed docs.

## Project

The Project area contains the main resources used by your visual novel.

- [Projects](/en/creator/docs/projects/): project list and basic project information
- [Images](/en/creator/docs/images/): background images, CGs, and other image assets
- [Sounds](/en/creator/docs/sounds/): audio assets such as BGM and sound effects
- [Videos](/en/creator/docs/videos/): video assets used in scenes
- [Characters](/en/creator/docs/characters/): character definitions and related resources
- [Transforms](/en/creator/docs/transforms/): reusable transform definitions
- [Animations](/en/creator/docs/animations/): reusable update and transition animations
- [Particles](/en/creator/docs/particles/): reusable particle effects
- [Spritesheets](/en/creator/docs/spritesheets/): spritesheet animation resources
- [Colors](/en/creator/docs/colors/): color definitions used across the UI
- [Fonts](/en/creator/docs/fonts/): font resources
- [Controls](/en/creator/docs/controls/): project-level control definitions
- [Variables](/en/creator/docs/variables/): project variables used by actions and conditions
- [Text Styles](/en/creator/docs/text-styles/): reusable text styling presets
- [Layouts](/en/creator/docs/layouts/): UI layouts and page structures

## Scene

The Scene area is where story content is organized and edited.

- [Scene Map](/en/creator/docs/scene-map/): high-level scene flow and structure
- [Scene Editor](/en/creator/docs/scene-editor/): detailed editing of scene lines and actions
