Text styles is to manage the typography

Common text styles to create are:

- Character name
- Dialogue content
- Menu text

## Create a text style

Following are properties you can edit for text styles

- Name
- Description
- Font file
- Font size
- Stroke color
- Stroke width
- Font weight
- Line height
- Preview text: defaults to name
