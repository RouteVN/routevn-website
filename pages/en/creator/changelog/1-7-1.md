This version adds sound playback while text is revealing, fixes text and font display issues, and improves page load performance.

## Changes

- Added support for playing sound while text is revealing.
- Improved the sound selector in the layout editor.
- Fixed an issue where some fonts displayed incorrectly.
- Fixed a bug in text input logic.
- Fixed a macOS scene editor bug related to line navigation.
- Fixed scrollbar color styling.
- Improved page load performance.
