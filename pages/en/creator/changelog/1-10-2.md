This version improves font handling, conditional actions, element selection, and the Layout Editor. It also adds platform-specific export settings, scene screenshots, overlay scrollbars, and important stability fixes.

## Changes

- Dropped support for uploading fonts in WOFF format. WOFF2 remains supported, and previously uploaded WOFF files will continue to work.
- Updated text styles to show only the font weights supported by the selected font.
- Added shadow support to text styles.
- Added better default fonts for new projects based on the project language, including an extended Latin font and dedicated fonts for CJK languages.
- Added `One Of`, `Greater Than`, `Greater Than or Equal`, `Less Than`, and `Less Than or Equal` evaluations to Conditional actions in the Scene Editor.
- **Breaking:** Updated Conditional actions to move automatically to the next line when none of their section transition conditions evaluate as true.
- Added element selection from the Layout Editor preview. Hover over and click an element to select it, or double-click a child of the currently selected container.
- Added support for the `Loop End` reveal-sound interruption option in the Layout Editor.
- Improved scrollbar presentation with overlay scrollbars.
- Added more than a dozen minor interface improvements, especially in the Layout Editor.
- Fixed a critical bug that could crash a project during refresh while a resource was still uploading.
- Improved the description for dialogue speaker sprites and made them persist by default.
- Added a Platform Details page for platform-specific export settings. It currently supports web exports, with more export platforms planned.
- Added a button to download screenshots from the Scene Editor.
