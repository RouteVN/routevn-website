This version adds voice actions, more layout sound support, spritesheet support for character group sprites, and dialogue text speed controls.

## Changes

- Fixed a critical bug when using hover and click sounds in layouts.
- Added hover and click sound support for image and container elements.
- Added `revealing` and `complete` click-to-continue indicator support for revealing text.
- Added spritesheet support for character group sprites.
- Added the Voice action.
- Added a dialogue text speed override option.
