This version fixes scene preview keyboard handling, improves older project compatibility, and makes portrait project previews more reliable.

## Changes

- Fixed full-screen scene preview controls so pressing Enter works in the preview instead of adding a new line in the editor.
- Improved keyboard shortcut compatibility for the scene preview on Windows and macOS.
- Improved compatibility for older or imported projects that include previous section delete history.
- Kept existing 1080x1920 portrait projects supported while hiding that preset from the new project form.
- Fixed the scene preview canvas size for portrait projects.
- Fixed a scene editor issue where the sections list could scroll incorrectly.
- Improved error messages when the app cannot open an external link.
- Allowed RouteVN documentation links to open from inside the desktop app.
- Cleaned up scene editor paste handling.
