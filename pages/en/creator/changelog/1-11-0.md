This version adds desktop exports, redesigned editors, dedicated audio channels, computed variables, and localized interfaces. It also brings UI/UX improvements across the Scene Editor, Layout Editor, and Project page.

## Changes

- **[BETA] Export:** Added export to a Windows executable.
- **[BETA] Export:** Added export to a macOS executable.
- **[BETA] Localization:** Added Japanese and Chinese interface translations.
- **Audio:** Added channel support for sounds, with dedicated channels for BGM, Voice, and SFX.
- **Variables:** Added support for computed variables.
- **Scene Editor:** Added support for rotation.
- **Scene Editor:** Improved the UI/UX of line actions.
- **Animation Editor:** Redesigned the Animation Editor page.
- **Layout Editor:** Improved the UI/UX of the Layout Editor page.
- **Project Page:** Added a resources overview.
- **Particles Editor:** Fixed bugs in the Particles Editor.
- **General:** Included additional bug fixes and stability improvements.
