This version adds project language settings, language-aware text counts, and spritesheet support for backgrounds and visuals. It also improves full-screen and page navigation behavior and fixes scene and layout editor issues.

## Changes

- Added a language option during project creation. Existing projects default to English.
- Added character or word counts to the scene editor based on the project language.
- Updated the Windows title bar so it is hidden in full-screen mode.
- Fixed a layout editor issue where font weight was not respected.
- Fixed incorrect line selection behavior in the scene editor.
- Added spritesheet support for backgrounds and visuals in the scene editor.
- Updated keyboard shortcuts for page navigation.
