This version updates the app icon, add blur support, improved visuals scene controls, and more.

## New app icon

![RouteVN Creator 1.4.2 app icon](/public/creator/changelog/1-4-2-icon.png)

## Changes

- Supports blur of background and screen
- Added richer visual controls for scene actions. Opacity and blur can now be applied to backgrounds, characters, screen effects, and added visual items.
- Added visual layers. Layers allows more granular control on the z index of the visual assets
- Visual support picker with separate Images, Videos, and Layouts tabs.
- Add support for duplicate and moving of sections to other scenes
- Expanded animation editing with more tween properties, including rotation, translate X/Y, and blur X/Y.
- Image and character sprite previews now support previous and next navigation from the preview overlay.
- Improved scene editor page loading and 1st render experience
